I work on governance and compliance automation for a Microsoft 365 tenant of more than 200,000 users, mostly with PowerShell and Microsoft Graph. The repositories below are public versions of some of that work.

## Repositories

- [M365-Governance-Automation-Framework](https://github.com/rajeshm365/M365-Governance-Automation-Framework): PowerShell and Azure Logic Apps framework that monitors Teams admin settings and Purview retention policies, so configuration changes are detected automatically.
- [OneDrive-IB-Segment-AutoRemediation](https://github.com/rajeshm365/OneDrive-IB-Segment-AutoRemediation): weekly PowerShell job that scans OneDrive sites for missing Information Barrier segments and applies the correct segment.
- [PublicGroup-Visibility-AutoRemediation](https://github.com/rajeshm365/PublicGroup-Visibility-AutoRemediation): daily PowerShell job that finds Microsoft 365 Groups set to Public and makes them Private by applying a sensitivity label to the group or its site.
- [License-and-Group-Monitoring-LogicApps](https://github.com/rajeshm365/License-and-Group-Monitoring-LogicApps): two Azure Logic Apps using Managed Identity and Microsoft Graph that alert when licence capacity or monitored-group capacity drops below a threshold.
